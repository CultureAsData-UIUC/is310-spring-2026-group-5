# Methodology

## Project Topic
This project examines how scholarly sources discuss artificial intelligence in K-12 education, especially in relation to productivity, teaching, learning support, academic integrity, and educational policy.

## Dataset Creation Process
The dataset was created by collecting scholarly articles, book chapters, conference papers, and academic reports related to AI use in K-12 education. Each row represents one source. I manually reviewed article titles, abstracts, and available source descriptions, then categorized each source using interpretive labels.

## Computational Process
Python was used to create and update the CSV dataset. The script helped standardize the dataset columns and convert spreadsheet data into CSV format.

## Manual Annotation
The dataset includes manual categories such as education level, AI tool, main theme, secondary theme, tone, benefits discussed, concerns discussed, student group, and notes.

## Limitations
This dataset does not measure actual student productivity directly. Instead, it studies how scholarly literature discusses AI use in K-12 education. Some sources had incomplete metadata, and some article information was based on abstracts rather than full-text reading.

## Ethical Considerations
Because this project uses scholarly sources rather than student records, surveys, or private classroom data, it avoids collecting sensitive student information. However, the dataset still reflects biases in published academic literature, including which countries, institutions, and perspectives are represented.
